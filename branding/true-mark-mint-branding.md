# True Mark Brand and Product Language

## Positioning

True Mark is an object-authentication and evidence-preservation platform. It issues Prime Layer Certificates from sealed records and offers optional digital extensions afterward.

## Primary concepts

- Perpetuum: private, mutable working space.
- Object Workbench: project workspace for identity, ownership, provenance, evidence, and certificate configuration.
- Immutable Vault: authoritative append-only record.
- Prime Layer Certificate: derived certificate with governed 2/3/5/7/11/13 evidence depth.
- Human Support: scoped human-agent escalation, hidden by default.

## Tone

Use precise, institutional, calm language. Prefer “authenticate an object,” “stage evidence,” “commit,” “seal,” “verify,” and “certificate profile.” Use “mint” only when a token is genuinely being created.

## Visual direction

Elegant, secure, institutional, and legacy-focused. Visual design must remain independent from forensic depth: certificate frame, typography, paper, seal, watermark, layout, orientation, palette, and image placement are render choices, not evidence claims.
