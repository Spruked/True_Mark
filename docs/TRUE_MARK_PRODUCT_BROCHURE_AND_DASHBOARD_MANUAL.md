# True Mark Mint — Product Brochure and Dashboard User Manual

## Product Brochure

### What Is True Mark Mint?

True Mark Mint is a forensic vault issuance engine that transforms knowledge, expertise, and intellectual property into cryptographically secured digital certificates.

True Mark Certificates are encrypted, license-bound, forensically traceable, multi-chain anchored, and designed for long-term authority and control. True Mark is infrastructure for issuing digital authority, not a marketplace.

### Who Uses True Mark?

- Subject matter experts: mechanics, electricians, chefs, instructors, consultants, and educators.
- Enterprises: training departments, franchise systems, IP holders, and certification bodies.
- Families and estates: heirloom preservation, succession planning, and private archives.
- Creators and innovators: course builders, method developers, and system architects.

### Technology Stack

- ChaCha20 secure vault encryption at source.
- Prime-number forensic certificate layers: 2, 3, 5, 7, 11, and 13.
- Guilloche geometry, micro-noise entropy fields, invisible per-mint watermarking, Ed25519 issuer signatures, anti-AI rendering, and QR verification anchors.
- Multi-chain anchoring across Polygon, Ethereum, and Arbitrum.
- License-first smart contracts with rights, royalty, sublicensing, and soulbound options.

### Asset Taxonomy

- **K-Series — Knowledge & Expertise:** for instructors and specialists.
- **H-Series — Heirloom & Inheritance:** for private family archives.
- **L-Series — Legacy & Business:** for commercial systems and scalable IP.
- **HL / KL / LL / BL licensable variants:** H, K, L, and B retain their base color family; the `L` suffix records licensing and does not create a new type family.
- **C:** Custom Contract NFT. Enterprise is an Alpha CertSig Mint licensing model, not a True Mark NFT type.

## Dashboard User Manual

### Overview

The True Mark Dashboard is the operational interface for creating encrypted vaults, uploading knowledge assets, generating forensic certificates, issuing licensed NFTs, and managing ownership and access.

### Dashboard Sections

- Home
- Minting
- Vault
- Certificates
- Account
- Settings

### Certificate Creation Flow

1. Select a certificate series: KL-Series (Knowledge), HL-Series (Heirloom), or LL-Series (Legacy).
2. Upload PDF, DOCX, MP4, MP3, PNG/JPG, ZIP, or proprietary assets. Content is encrypted immediately on upload.
3. Enter title, description, license class, royalty percentage, and optional expiration or renewal logic.
4. Preview forensic rendering: Guilloche patterns, micro-noise fields, invisible watermark, Ed25519 signature, and QR verification code.
5. Select a network: Polygon, Ethereum, or Solana. Display regular fiat pricing with crypto equivalent at time of purchase.

### Vault

- Encrypted file storage.
- Decryption key management.
- Access logs.
- Token-gated delivery.
- Time-limited access keys.

### Certificate Management

Display token ID, owner, license class, royalty settings, forensic watermark ID, transfer controls, and revocation/expiration state. LL-Series supports renewal fees, expiration dates, and revocation conditions.

### Attestation System

Experts can issue cryptographic attestations for course completion, skills, professional endorsements, and class completion. Attestations are signed with the master wallet.

### Security

Zero plaintext storage, ChaCha20 encryption, Ed25519 signatures, per-mint forensic watermarking, multi-chain anchoring, vault access logging, and anti-AI rendering.

### Support

Support channels include email support, an operator Discord channel, and enterprise LL-Series support.
