# Demonstration certificates

This folder is intentionally separate from `certificates/issued/`.

It contains four non-authoritative presentation examples generated by
`certificate_generator_2x/truemark/forge_v2.0/generate_examples.py`:

- K-NFT, 7-layer
- K-NFT, 13-layer
- HL-NFT, 7-layer
- HL-NFT, 13-layer
- L-NFT, 7-layer — alternate compact Tree watermark and Victorian frame
- B-NFT, 13-layer — signature Tree watermark and Hex-Grid frame

Each uses fictional identifiers, wallet, IPFS reference, signature, and
verification state. Every artifact is visibly marked **DEMONSTRATION — NOT
ISSUED, NOT REGISTERED, NOT VALID FOR VERIFICATION**. Never move an example
into an issued-certificate directory or a public registry.
